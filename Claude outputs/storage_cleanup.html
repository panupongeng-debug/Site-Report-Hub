🧹 ล้างไฟล์ที่ไม่มีการอ้างอิงใน Supabase Storage

เครื่องมือนี้ตรวจหาไฟล์ใน Storage bucket evidence-photos ของ Site Reports Hub ที่ "ไม่มีแถวข้อมูลใดในตารางไหนเลย" อ้างอิงถึงอีกต่อไป (เช่น รูป/ไฟล์แปลนที่แถวข้อมูลถูกลบไปแล้ว แต่ตัวไฟล์จริงในที่เก็บยังค้างอยู่) — เป็นการตรวจสอบแบบอ่านอย่างเดียวก่อนเสมอ จะไม่มีการลบอะไรจนกว่าคุณจะกดปุ่ม "ลบไฟล์ที่เลือก" เอง และไฟล์ที่จะลบได้ต้องเป็นไฟล์ที่ไม่มีการอ้างอิงเหลืออยู่เลยเท่านั้น จึงไม่กระทบเว็บที่ใช้งานอยู่ (ไม่มีหน้าไหนในระบบเปิดไฟล์เหล่านี้อยู่แล้ว)

⚠️ การลบไฟล์ใน Storage ย้อนกลับไม่ได้ — แนะนำให้ตรวจสอบรายการก่อนลบเสมอ โดยเฉพาะถ้าเพิ่งอัปโหลด/ลบข้อมูลอะไรในช่วง 1-2 นาทีที่ผ่านมา (เผื่อกรณีอัปโหลดค้างระหว่างขั้นตอน ยังไม่ทันบันทึกแถวข้อมูลลงตาราง) เปิดหน้านี้จากเครื่องที่เชื่อถือได้เท่านั้น เพราะไฟล์นี้มี URL/anon key ของฐานข้อมูลอยู่ในตัว (ค่าเดียวกับที่ฝังอยู่ในเว็บ Site Reports Hub ที่ deploy จริงอยู่แล้ว ไม่ใช่ความลับใหม่ที่หลุดออกไป)
